**Biblioteca Personal**

Este proyecto es una aplicación en Python que permite gestionar una biblioteca personal utilizando una base de datos SQLite.
El usuario puede agregar, actualizar, eliminar, ver y buscar libros desde un menú interactivo en consola.

 **Funcionalidades**

Agregar libros con título, autor, género y estado (leído / no leído)

Actualizar información de un libro

Eliminar libros por ID

Mostrar listado completo de libros

Buscar libros por título, autor o género

🗄 Base de Datos

El programa usa SQLite y crea automáticamente el archivo biblioteca.db con la tabla:

libros

id

titulo

autor

genero

estado

**Cómo ejecutar**

Asegúrate de tener Python 3 instalado

Ejecuta el programa con:

python biblioteca.py
